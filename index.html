Smartsheet sync setup guide

Smartsheet's API can't be called directly from a browser (no CORS support), so a small Cloudflare Worker sits in between and holds your API token securely. See the worker.js + setup instructions provided alongside this app.

  1. In Smartsheet, create 3 sheets: QC, Board, Issues, with column titles matching those listed in worker.js
  2. Generate a Smartsheet API access token: Account → Personal Settings → API Access
  3. Deploy worker.js as a Cloudflare Worker (free tier is fine)
  4. In the Worker's settings, add secrets: SMARTSHEET_TOKEN, QC_SHEET_ID, BOARD_SHEET_ID, ISSUES_SHEET_ID, ALLOWED_ORIGIN
  5. Copy your Worker's URL (e.g. https://your-worker.workers.dev) and paste it above as the sync URL

ⓘ How to import into Smartsheet
  1. Download the export file above
  2. In Smartsheet → click + (New) → Import → CSV / Excel
  3. Select your downloaded file → click Next
  4. Smartsheet auto-detects column types — verify dates are Date type, checkboxes are Checkbox
  5. Click Import — your sheet is ready
  6. For auto-refresh: use Data Shuttle (Smartsheet Business/Enterprise) to schedule hourly imports from your Google Sheet
